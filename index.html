          For agent sites

          Kongsi is an open agentic website. Its agent network is public data that any browser runtime can load, and its assistant runs entirely in your browser on the AI provider you choose.

          A restaurant's or a trip planner's assistant can hand a bill to Kongsi. After its visitor agrees on a consent card, Kongsi's network runs in that visitor's browser and uses Kongsi's shared calculate_split tool, which runs Kongsi's own code on Kongsi's origin. It reads nothing from this page and keeps nothing.
